# The Lifestyle Journal

## Description

The Lifestyle Journal is a responsive personal portfolio website developed using HTML, CSS, and JavaScript. This project was created as part of my web development learning journey to showcase my interests, hobbies, experiences, and creative works in an engaging and visually appealing way.

The website serves as a digital journal where visitors can explore different aspects of my lifestyle, including photography, travel experiences, food hunting adventures, technology interests, and creative projects. Through this project, I applied front-end web development concepts such as responsive design, user interface design, and interactive JavaScript functionality.

The main goal of this project is to create a user-friendly and aesthetically pleasing portfolio website while strengthening my practical skills in HTML structure, CSS styling, and JavaScript programming.

---

## Features

- Responsive website layout that adapts to desktop and mobile devices.
- Home page introducing the website and highlighting personal interests.
- About page containing personal background, education, skills, and hobbies.
- Blog page featuring lifestyle-related content and journal entries.
- Photography gallery showcasing personal photography collections.
- Food hunting gallery displaying favorite food discoveries and experiences.
- Travel gallery featuring memorable travel destinations and experiences.
- Interactive image pop-up gallery implemented using JavaScript.
- Contact page with social media links and WhatsApp contact functionality.
- GitHub Pages deployment for online accessibility.

---

## Technologies Used

### HTML5
Used to create the structure and content of the website pages.

### CSS3
Used for styling, responsive layouts, color schemes, typography, and visual presentation.

### JavaScript
Used to implement interactive features such as the gallery pop-up modal and user interactions.

### Git & GitHub
Used for version control, project management, and repository hosting.

### GitHub Pages
Used to deploy and publish the website online for public access.
